## Web-Obs 0.2.0

A much deeper audit, still fully local.

**New**
- Around 40 new page checks: thin content, readability, duplicate meta tags, mixed content, render-blocking resources, DOM size, URL quality, social tags, basic accessibility and more.
- A site audit: duplicate and near-duplicate pages, a fix list for internal links, internal link opportunities, conflicting canonical and noindex signals, pages competing for one topic, crawl traps, stale pages, trust pages and structured data checked against Google's rich result requirements.
- Certificate expiry, HSTS, Content Security Policy and cookie checks. Optional email DNS checks (SPF, DMARC, DKIM, CAA).
- A browser sample of up to five pages: lab timings, automated accessibility rules (axe-core), screenshots, JavaScript dependence and third parties on first load.
- `_audit.md`, `_findings.csv`, a Page Audit section in every note, and `_tasks.md`, a checklist that remembers your ticks and closes tasks the next capture no longer finds.
- A command to compare two captured sites side by side.
- Notes that mirror the page: header, navigation and footer kept as labelled regions, readable media and link sections, and a full-page snapshot of the most important pages at the top of each note.
- A calmer interface: a slim toolbar, tabbed Site Intel and page panels, charts in the Site audit, and a 3D map with fewer, non-overlapping labels.
- An honest crawler: the user agent is now `Mozilla/5.0 (compatible; WebObs/0.2.0; +https://github.com/AgriciDaniel/web-obs/blob/main/docs/CRAWLER.md)`, robots.txt `Crawl-delay` is honoured, and the capture backs off when a site answers 429 or sends `Retry-After`. Site owners can read [what WebObs sends](https://github.com/AgriciDaniel/web-obs/blob/main/docs/CRAWLER.md).

**Optional packages** `dnspython`, `pyspellchecker` and `html5lib` unlock email DNS, spell check and HTML validation. Web-Obs works without them.

**Needs** Obsidian 1.5.0 or newer on desktop, and Python 3.14 or newer (see the README for the short setup).

**Install** Download `main.js`, `manifest.json` and `styles.css` from this release into `YOUR-VAULT/.obsidian/plugins/web-obs/`. Web-Obs unpacks its capture engine on first start.

Full details are in the [changelog](https://github.com/AgriciDaniel/web-obs/blob/main/CHANGELOG.md).
