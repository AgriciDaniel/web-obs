## Web-Obs 0.1.1

Accuracy fixes from a full capture of a live WordPress site.

**Fixed**
- Sites that use trailing slashes (like WordPress) no longer show nearly every page as a redirect. Pages are fetched and saved at the address the site publishes.
- Pages missing from the sitemap are counted even when they also redirect.
- A sitemap that several addresses lead to is counted once.

**Changed**
- Response time now measures the final page request only, so redirects no longer inflate it.
- Empty alt text on decorative images is no longer an error. Only a missing alt is.
- Heading level skips in headers, menus and footers are counted apart from the page content.
- A broken image or page found during a capture is listed as a finding and no longer marks the whole capture as partial.
- Internal links written without the site's trailing slash are listed on the page that contains them.

**Needs** Obsidian 1.5.0 or newer on desktop, and Python 3.14 or newer (see the README for the short setup).

**Install** Download `main.js`, `manifest.json` and `styles.css` from this release into `YOUR-VAULT/.obsidian/plugins/web-obs/`. Web-Obs unpacks its capture engine on first start. The zip holds the same files if you prefer one download.

A site first captured with 0.1.0 may show its addresses as changed on the first recapture. Full details are in the [changelog](https://github.com/AgriciDaniel/web-obs/blob/main/CHANGELOG.md).
