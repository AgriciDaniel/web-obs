## Web-Obs 0.1.0

First release. Type a website address and Web-Obs saves its pages as Markdown notes in your vault, then draws the whole site as an interactive 3D globe.

**Highlights**
- A clean note for every page, with images saved locally
- Globe, Road and Clusters views of the site structure
- A health card (crawlable, searchable, AI ready, secure, links, speed signals) and a checklist of discovery files such as sitemap, robots.txt and llms.txt
- A site audit with charts and findings that link back to the source page
- A built-in diagnostics command that checks your setup and explains how to fix problems
- Everything runs locally. No account, no tracking, no AI service, no API key.

**Needs** Obsidian 1.5.0 or newer on desktop, and Python 3.14 or newer (see the README for the short setup).

**Install** Download `main.js`, `manifest.json` and `styles.css` from this release into `YOUR-VAULT/.obsidian/plugins/web-obs/`. Web-Obs unpacks its capture engine on first start. The zip holds the same files if you prefer one download.

Full details are in the [changelog](https://github.com/AgriciDaniel/web-obs/blob/main/CHANGELOG.md).
