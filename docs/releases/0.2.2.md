## Web-Obs 0.2.2

Safer page reading, cleaner logos in notes, and a proper cancel on Windows.

**Fixed**
- Closing tag text inside a page is left alone. 0.2.1 deleted the text `</body>` or `</html>` wherever it appeared, for example in a title such as "How to close </body> tags". Only the page's real closing tags are moved now.
- A logo inside a link stays an image in the note, instead of turning into text in the link label.
- Cancelling a capture on Windows now lets the engine clean up, and ends its workers and browser too if it does not stop in time. The engine also stops if Obsidian quits during a capture.

**Changed**
- A more careful explanation of the 0.2.1 fix: on GitHub's Windows runner, lxml 6.1.3 with its bundled libxml2 2.11.9 dropped content after `</html>`. The earlier notes blamed every libxml2 before 2.14, which is broader than what was shown.

**Needs** Obsidian 1.5.0 or newer on desktop, and Python 3.14 or newer (see the README for the short setup).

**Install** Download `main.js`, `manifest.json` and `styles.css` from this release into `YOUR-VAULT/.obsidian/plugins/web-obs/`. Web-Obs unpacks its capture engine on first start. The zip holds the same files if you prefer one download.

Full details are in the [changelog](https://github.com/AgriciDaniel/web-obs/blob/main/CHANGELOG.md).
