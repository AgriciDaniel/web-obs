## Web-Obs 0.2.1

Windows captures now see the whole page.

**Fixed**
- Links, images and text that a page places after its closing `</html>` tag are captured on every system, as browsers show them. On Windows they were lost, because the lxml package there bundles an older libxml2 that drops them. This was the known Windows image problem.

**Changed**
- The README shows the Windows setup: the PowerShell commands and the `Scripts\python.exe` path for the settings.

**Needs** Obsidian 1.5.0 or newer on desktop, and Python 3.14 or newer (see the README for the short setup).

**Install** Download `main.js`, `manifest.json` and `styles.css` from this release into `YOUR-VAULT/.obsidian/plugins/web-obs/`. Web-Obs unpacks its capture engine on first start. The zip holds the same files if you prefer one download.

Full details are in the [changelog](https://github.com/AgriciDaniel/web-obs/blob/main/CHANGELOG.md).
